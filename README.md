# うるるといえ 詩集

起動: `npm install` → `npm run dev` ／ ビルド: `npm run build`（`dist/` をVercelへ。GitHubへpushすれば既存フローで公開）

## 構成
- `src/data/songs.js` 歌詞データ（原稿から抽出。表示のために加工・変更しない）
- `src/lib/phrases.js` 表示専用：原稿1行内の全角スペースごとに画面上の独立した1行へ分ける（行頭の全角スペースは字下げとして保持、空行は段落の空き）
- `src/views.jsx` 表紙・目次・歌詞ページ ／ `src/styles/` 固定のタイポ設計値と共通CSS
- `src/lib/theme.js` **デザイン設定の一元管理**（色・書体・文字サイズ・行間・各行の余白・曲名と歌詞の間・ページ余白・線の濃さ）
- `src/design/` デザイン調整画面

## デザインの調整方法
1. `https://（公開URL）/#/design` を開く（どこからもリンクしていません。秘密ではありません）
2. スライダー等で調整。表紙・目次・歌詞のプレビュー（スマホ幅 360/390/430px）が即座に変わる。曲ごとの個別調整（文字サイズ・行間・各行の間隔・曲名との間）も可能
3. 「設定コードをコピー」→ `src/lib/theme.js` の `defaultTheme` に貼り付け → ブランチでcommit → GitHub → Vercelで公開

この画面の変更は**プレビューのみ**で、保存されず、公開サイトにも他の閲覧者にも反映されません。

## 将来の拡張（自動スクロール・演出）
歌詞は `Lyrics`（views.jsx）が1行ずつ `<p class="line">` として並べ、見た目は theme.js のCSS変数だけで決まります。スクロール制御のフックや演出は、この層に追加してください。
