# うるるといえ 詩集

曲名・曲順・歌詞・写真は、すべてソースコード内のデータで管理します。データベース・管理画面・ログイン・環境変数は不要です。

起動: `npm install` → `npm run dev` ／ ビルド確認: `npm run build`

## 画面
- `#/` 表紙 ／ `#/songs` 目次 ／ `#/songs/<曲のid>` 歌詞
- `#/design` デザイン調整（プレビュー専用。どこからもリンクしていません。気に入った設定の「設定コード」を `src/lib/theme.js` に貼って反映します）

## 構成
| ファイル | 役割 |
|---|---|
| `src/data/songs.js` | **曲名・曲順・歌詞・写真パス**（編集するのは基本的にここだけ） |
| `public/images/songs/` | 曲ごとの写真を置くフォルダ |
| `src/lib/songs.js` | データを表示順に並べる（歌詞には手を加えない） |
| `src/lib/lyrics.js` | 歌詞の文字列を段落・行に分ける（改行・空行の解釈） |
| `src/views.jsx` | 表紙・目次・歌詞ページ。歌詞本文の表示は `LyricsText`、表示方式の選択は `displayModes` |
| `src/lib/theme.js` / `src/styles/` | デザイン設定とCSS |
| `src/design/` | デザイン調整画面 |

## 歌詞・曲名の変更
`src/data/songs.js` を開き、該当する曲を直接編集します。歌詞は `text`...`` の中にそのまま書きます。

```js
{
  id: 'ienai-koto',          // URL(#/songs/ienai-koto)になるので、公開後は変えない
  order: 1,                  // 表示順（小さい順）
  title: '「言えないこと」',   // 未確認なら null
  photo: null,               // 写真なし
  lyrics: text`
誰にも言えないこと　誰にも言いにくいこと
言葉にしづらい気持ち

次の段落
`,
},
```

## 曲の追加・削除・並べ替え
- 追加：`songs` 配列に1曲ぶんを足し、`id`（半角英数字とハイフン、他と重複しない）と `order` を決めます。
- 削除：その曲のブロックを消します。
- 並べ替え：`order` の数字を入れ替えます（配列内の位置は関係ありません）。
- 目次の番号は表示順に自動で振られます。

## 歌詞の組版ルール（入力した文字列は自動整形しません）
- 改行 → 次の行として表示
- 空行 → 段落の区切り（空行を重ねるほど間が広がる）。「空行」は何も書かれていない行です。全角スペースだけの行は、1行として表示されます
- 行頭の全角スペース → 字下げ ／ 行の途中の全角スペース → 言葉の間隔。連続していても、そのまま表示します
- 全角スペースを自動で改行にしたり、空白を詰めたりしません（CSSは `white-space: pre-wrap`）
- 画面幅で折り返した続きの行は、字下げ＋1字ぶん下がるので、入力した改行と見分けられます
- `text`...`` の直後と閉じる直前の改行は取り除かれます。歌詞の中に「`」と「${」は使えません
- エディタの「行末の空白を自動削除」設定はオフにしてください（行末の全角スペースも保持されます）

行の途中の全角スペースが長い行を作り、画面幅で折り返す場合は、その全角スペースを改行に書き換えると、1行ずつ独立して表示されます。

## 曲ごとの写真（任意）
1. 画像（JPEG / PNG / WebP。長辺1600px前後・1MB以下を推奨）を `public/images/songs/` に置く（ファイル名は半角英数字とハイフン）
2. `songs.js` の該当する曲の `photo` に `'images/songs/ファイル名.jpg'` と書く
3. 差し替えるときは、画像ファイルを同じ名前で置き換えるか、`photo` のパスを変える。外すときは `photo: null`

写真は曲名の上に、縦横比を保ったまま画面幅に合わせて表示されます。`photo: null` の曲は、写真用の空白のない、文字だけの表示です。

## 公開手順（GitHub → Vercel）
1. 変更したファイル（`src/data/songs.js`、`public/images/songs/` の画像など）をコミットする（できればブランチを切る）
2. GitHubにpushする（ブランチの場合は、確認後にmainへマージする）
3. Vercelが自動でビルド・デプロイし、公開ページが更新される（ビルド設定はこれまでと同じ）
4. 公開URLを開いて、表紙・目次・変更した曲のページを確認する
