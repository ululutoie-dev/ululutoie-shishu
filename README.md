# うるるといえ 詩集

詩集・曲・歌詞・写真・色は、すべてソースコード内のデータで管理します。データベース・管理画面・ログイン・環境変数は不要です。

起動: `npm install` → `npm run dev` ／ ビルド確認: `npm run build`

## 画面
- `#/` 共通表紙（詩集一覧） ／ `#/collection/<詩集id>/songs` 詩集の目次 ／ `#/collection/<詩集id>/songs/<曲id>` 歌詞
- 旧URL `#/songs` と `#/songs/<曲id>` は、引き続き詩集1として使えます
- `#/design` デザイン調整（プレビュー専用。どこからもリンクしていません。気に入った設定の「設定コード」を `src/lib/theme.js` に貼って反映します）

## 構成
| ファイル | 役割 |
|---|---|
| `src/data/collections/<詩集id>.js` | **1詩集＝1ファイル。詩集の設定（題名・並び・色）と全曲の歌詞**（普段編集するのはここだけ） |
| `src/data/templates/new-collection.js` | 新しい詩集のひな形（コピーして使う。このファイル自体は使われない） |
| `src/data/registry.js` | `collections/` 内のファイルを自動で読み込む（編集しない） |
| `src/data/songs.js` | 読み込んだデータをアプリの形に整える（表紙の名前 `book` はここ） |
| `public/images/` | 写真・イラストの置き場 |
| `src/views.jsx` | 表紙・目次・歌詞ページ。歌詞本文の表示は `LyricsText`、表示方式の選択は `displayModes` |
| `src/lib/` | `lyrics.js`（改行・空行の解釈）、`songs.js`（表示用の曲リスト）、`theme.js`（標準のデザイン設定・色の適用） |
| `src/design/` | デザイン調整画面 |

## 新しい詩集を追加する
1. `src/data/templates/new-collection.js` を `src/data/collections/` にコピーし、ファイル名を詩集の id にする（例：`shishu-3.js`）
2. 中身を書き換える：`id`（半角英数字とハイフン。他と重複しない。公開後は変えない）、`order`（詩集の並び順）、`title`、`theme`（背景色・文字色）、曲
3. GitHubに反映する。表紙の詩集一覧と目次に自動で出ます（他のファイルは編集しません）

## 曲を追加・変更・削除・並べ替える
詩集のファイル（`src/data/collections/<詩集id>.js`）の `songs` 配列を編集します。

```js
{
  id: 'sorairo-no-ue',     // URLになる。この詩集の中で重複しない。公開後は変えない
  title: '空色の上',        // 未確認なら null（目次では「（曲名未確認）」と表示）
  photo: null,             // 写真なし。あり: 'images/shishu-2/sorairo-no-ue.jpg'
  lyrics: text`
誰のためでもない
意味のないことばっか

次の段落
`,
},
```
- 追加：`songs` 配列に1曲ぶん（`{ ... },`）を足す
- 削除：その曲のブロックを消す
- 並べ替え：ブロックを入れ替える（**配列に書いた順が表示順**。目次の番号も自動で振られます）

## 詩集ごとの色（テーマ）
詩集ファイルの `theme` に、背景色 `bg` と文字色 `ink` を書きます。薄いグレーの補助文字や罫線は、この2色から自動で作られます。

```js
theme: { bg: '#f4eee0', ink: '#2a2521' },   // 詩集2：生成り色
```
- 省略した項目は標準（白背景 `#ffffff`・文字 `#1c1c1c`）になります
- 表紙とデザイン調整画面は、共通の標準デザインです
- `npm run dev` の間、背景と文字のコントラストが低すぎる（4.5:1未満）と、ブラウザのコンソールに警告が出ます

## 歌詞の組版ルール（入力した文字列は自動整形しません）
- 改行 → 次の行として表示
- 空行 → 段落の区切り（空行を重ねるほど間が広がる）。「空行」は何も書かれていない行です。全角スペースだけの行は、1行として表示されます
- 行頭の全角スペース → 字下げ ／ 行の途中の全角スペース → 言葉の間隔。連続していても、そのまま表示します
- 全角スペースを自動で改行にしたり、空白を詰めたりしません（CSSは `white-space: pre-wrap`）
- 画面幅で折り返した続きの行は、字下げ＋1字ぶん下がるので、入力した改行と見分けられます
- `text`...`` の直後と閉じる直前の改行は取り除かれます。歌詞の中に「`」と「${」は使えません
- エディタの「行末の空白を自動削除」設定はオフにしてください（行末の全角スペースも保持されます）

行の途中の全角スペースが長い行を作り、画面幅で折り返す場合は、その全角スペースを改行に書き換えると、1行ずつ独立して表示されます。

## 曲ごとの写真（任意）
1. 画像（JPEG / PNG / WebP。長辺1600px前後・1MB以下を推奨）を `public/images/` の下に置く（例：`public/images/shishu-2/sorairo-no-ue.jpg`。ファイル名は半角英数字とハイフン）
2. 曲の `photo` に `'images/shishu-2/sorairo-no-ue.jpg'` と書く
3. 差し替えるときは、画像ファイルを置き換えるか、`photo` のパスを変える。外すときは `photo: null`

写真は曲名の上に、縦横比を保ったまま画面幅に合わせて表示されます。`photo: null` の曲は、写真用の空白のない、文字だけの表示です。

## 詩集のジャケット画像（目次ページの上部に表示）
詩集のid（`shishu-1` など）と同じ名前の画像を、`public/covers/` に置くだけで表示されます。データやコードの編集は不要です。

| 詩集 | 画像のファイル名 |
|---|---|
| 詩集1 | `public/covers/shishu-1.jpg` |
| 詩集2 | `public/covers/shishu-2.jpg` |
| 詩集3 | `public/covers/shishu-3.jpg` |
| 詩集4 | `public/covers/shishu-4.jpg` |

- **差し替え**：同じファイル名の画像をGitHubにアップロードして上書きする（Vercelの自動デプロイで反映）。拡張子を変えたい場合は `.png` / `.webp` でも読み込まれます（古い `.jpg` は消す）。
- **新しい詩集**：その詩集のid（例：`shishu-5`）と同じ名前で `public/covers/shishu-5.jpg` を置く。
- **画像がない詩集**：ジャケットは表示されず、これまでどおりのページです。
- **表示**：目次の上部ナビのすぐ下に中央揃え、幅200px（狭い画面では自動で縮小）、縦横比は維持。正方形（1200×1200px程度・500KB以下）がおすすめです。
- 別のファイル名を使いたいときだけ、詩集データ（`src/data/collections/<id>.js`）に `cover: 'covers/xxx.jpg'` を足します。

## 公開手順（GitHub → Vercel）
1. 変更したファイル（詩集ファイル、`public/images/` の画像など）をコミットする（できればブランチを切る）
2. GitHubにpushする（ブランチの場合は、確認後にmainへマージする）
3. Vercelが自動でビルド・デプロイし、公開ページが更新される（ビルド設定はこれまでと同じ）
4. 公開URLを開いて、表紙・目次・変更した曲のページを確認する

## 今後の拡張（イラスト・アニメーションなど。まだ実装していません）
- データと表示は分離してあります。歌詞本文の表示は `LyricsText`（`src/views.jsx`）に集約し、改行・空行・全角スペースは `toParagraphs()`（`src/lib/lyrics.js`）の結果（段落 → 行）として扱えます。
- 曲に項目を足す形で増やします。写真は今の `photo`。イラストや複数枚の画像は、曲に `image` / `illustration` のような項目と、表示する場所（曲名の上・歌詞の下など）の指定を足し、`views.jsx` で表示します。
- アニメーションは、曲に `display: 'fade-lines'` のような指定を足し、対応する表示部品を `displayModes`（`src/views.jsx`）に追加します（未指定は通常表示）。段落と行の情報をそのまま使えるので、改行は失われません。端末の「視差効果を減らす」設定のときは通常表示にするのがおすすめです。
- 詩集ごとの見た目の指定（`theme`）も、同じ場所に項目を足して広げられます。
